## Sobre o projeto
O FinanSys e uma plataforma de gestao e controle financeiro pessoal e empresarial de pequeno porte. O sistema permite monitorar contas bancarias, organizar receitas e despesas por categorias, planejar orcamentos mensais, gerenciar compras parceladas e acompanhar investimentos e transferencias entre contas.

## Estrutura dos arquivos
**Laboratorio de Banco de Dados - FinanSys.sql**
Criacao do banco de dados e de todas as tabelas, com chaves primarias, estrangeiras e restricoes.

**Insercao_de_Dados.sql**
Populacao do banco com dados de exemplo, cobrindo usuarios, contas, cartoes, faturas, categorias, orcamentos, transacoes, parcelamentos e investimentos.

**Selecao_de_Dados.sql**
Consultas de exemplo para extrair informacoes do banco, como extrato de conta, gasto por categoria, consumo de orcamento e rentabilidade de investimentos.

**Atualizacao_de_Dados.sql**
Comandos de atualizacao de dados, como pagamento de fatura, atualizacao de saldo e ajuste de limites.

**Laboratorio de Banco de Dados - FinanSys.mwb**
Trata-se do Modelo Lógico do Banco de Dados, obtido através da ferramenta de engenharia reversa do MySQL Workbench

**LABORATÓRIO DE BANCO DE DADOS.drawio** e **LABORATÓRIO DE BANCO DE DADOS.drawio.html**.
São duas versões do Modelo Conceitual desenvolvido no **draw.io Diagrams**.

## Como executar
Executar o arquivo Laboratorio de Banco de Dados - FinanSys.sql para criar o banco e as tabelas.
Executar o arquivo Insercao_de_Dados.sql para popular o banco com dados de exemplo.
Executar os arquivos Selecao_de_Dados.sql e Atualizacao_de_Dados.sql conforme a necessidade.
